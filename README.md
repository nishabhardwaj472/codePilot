# ⚡ CodePilot

### Understand the codebase before you touch it.

> CodePilot turns unfamiliar repositories into interactive maps of architecture, dependencies, APIs, databases, and AI-powered engineering insights.

🌐 **Live Demo:** https://code-pilot-topaz.vercel.app/

---

## 🚀 What is CodePilot?

CodePilot is a **Codebase Intelligence Platform** that analyzes real software repositories and helps developers understand how an unfamiliar codebase works.

Instead of spending hours jumping between files and asking:

- Where does this API come from?
- Which controller handles this request?
- Which service calls this model?
- Which files depend on this module?
- Where does the database interaction happen?
- What does this architecture actually look like?

CodePilot gives you the answers through **static analysis, interactive visualizations, and Gemini-powered AI assistance**.

## ✨ Features

### 🧠 Real Codebase Analysis

CodePilot analyzes actual source code using AST-based static analysis.

It detects:

- Functions
- Classes
- Methods
- Interfaces
- Types
- Imports
- Exports
- Internal dependencies
- External packages
- API routes
- Database schemas
- Model relationships
- Architecture patterns

---
